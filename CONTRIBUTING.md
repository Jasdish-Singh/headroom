# Contributing

Bugs and patches are welcome on [Jasdish-Singh/headroom](https://github.com/Jasdish-Singh/headroom).

1. Use Python 3.11 or newer.
2. From a checkout: `python -m pip install -e ".[dev]"` and `python -m pytest`.
3. Cleanup stays on the built-in allowlist. A config file cannot add a path, and deletion still requires the user to type `YES`.

A patch is licensed under the MIT license in `LICENSE`.
