# Changelog

## 0.1.0

First public release.

- Watch RAM, commit, page file, and free disk space, with a tray icon and sign-in start.
- Allowlisted cache cleanup after `YES`. Review moves after `MOVE`, into the Recycle Bin or an archive.
- Local dashboard, history, and reports for duplicates, downloads, and startup programs.
- Roomy, a read-only desktop pet.
- MCP server (`headroom mcp`). `clean`, `move`, and `startup_disable` return plans.
