# Security

Report a vulnerability through [GitHub security advisories](https://github.com/Jasdish-Singh/headroom/security/advisories/new).

Do not open a public issue for a security bug.

Headroom deletes files only from its allowlist, and only after you type `YES`. A review move waits until you type `MOVE`. The MCP tools `clean`, `move`, and `startup_disable` return a plan and do not change the PC.
